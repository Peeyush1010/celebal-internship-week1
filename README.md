|------|-------------|

## 📋 Steps Covered
1. Load CSV into Pandas DataFrame
2. Explore data — head, shape, dtypes, describe
3. Handle missing values — fillna, dropna
4. Filter rows and select columns — loc, iloc
5. Remove duplicates
6. Create derived column — `total_amount = initial_price × quantity`
7. Save cleaned dataset as CSV

## 📊 Dataset
Indian e-commerce product catalog — 1,000 products across 97 categories
